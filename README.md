# PILLAI AUTO — Ather 450 Series Page

Dealer website page for PILLAI AUTO, an authorised Ather Energy dealership on
Rajiv Gandhi Salai (OMR), Perungudi, Chennai.

## Contents

- `450.html` — Standalone page covering the Ather 450 Apex, 450X, and 450S
  lineup: specs, comparison table, features, battery/warranty, colours,
  pricing, and a test-ride CTA. Pure HTML/CSS/JS, no build step.
- `assets/data/Ather_450_Media_Paths.xlsx` — Reference sheet of official
  Ather image and video asset URLs (for sourcing licensed marketing-kit
  media to slot into the page's placeholder sections).
